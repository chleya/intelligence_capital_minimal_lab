目标：
训练一个 Allocator，使其不读取任何世界手工特征，只根据 CapitalReport 绩效信号，在 mixed task stream 中动态分配资本，并超过 BestSingleCapital。

一、修订资本分类

将 IC-3A 的最小资本设为四类：

1. PolicyCapital
   用于 fixed-goal synthetic task。
   在 hidden-goal task 中预期弱。

2. PrototypeMemoryCapital
   代表 Memory / Prototype 经验资本。
   输出最近查询距离、coverage/local OOD、cost、recent regret。

3. ParametricCompressionCapital
   合并 AEP + Residual。
   不再在 IC-3A 中拆开二者。
   输出 outcome prediction confidence、recent regret、OOD score、cost。

4. GoalInferenceCapital
   新增资本。
   用于 hidden-goal / latent-goal / partial-observation task。
   从 partial observations 和 reward history 中推断当前 goal belief。
   输出 goal belief confidence、goal uncertainty、recent goal inference error、recommended action。

所有资本必须实现：
generate_report(context, history) -> CapitalReport
act(context, history) -> action
update(feedback) -> None

Allocator 不允许访问资本内部。

二、Mixed Task Stream

构造混合任务流：

Task A: Fixed-goal synthetic
- PolicyCapital 应该强。

Task B: Goal-transfer synthetic
- ParametricCompressionCapital 应该强。

Task C: Low-dimensional dense-support synthetic
- PrototypeMemoryCapital 应该强。

Task D: HiddenGoalGridWorld external
- GoalInferenceCapital 应该强。

注意：
Allocator 不允许接收 task_id / env_name / utility_type / state_dim。
它只能通过各资本的 CapitalReport 判断。

三、Allocator 类型

实现并比较：

1. BestSingleCapital
   事后最优单一资本，作为必须超过的硬基线。

2. UniformPortfolio
   等权组合。

3. RandomAllocator
   随机选择资本。

4. OracleHindsightAllocator
   每一步事后知道哪个资本最好，理论上限。

5. LearnedBanditAllocator
   输入 CapitalReport matrix。
   输出 capital weights。
   更新目标：realized_utility - cost。

6. MetaMLPAllocator
   输入 CapitalReport matrix。
   输出 capital weights。
   训练目标：minimize cumulative regret + cost penalty。

七、成功标准

Minimum pass:
1. LearnedAllocator cumulative_regret < BestSingleCapital cumulative_regret
2. LearnedAllocator cost_normalized_regret < BestSingleCapital
3. LearnedAllocator > UniformPortfolio
4. oracle_gap decreases over training
5. On HiddenGoalGridWorld, allocator gives nonzero weight to GoalInferenceCapital
6. After task transition, allocator reduces weight of impaired capital within M steps

Strong pass:
1. LearnedAllocator beats BestSingleCapital by >5%
2. Beats BestSingleCapital on both SYNTH-ONLY and EXTERNALLY_VALIDATED splits
3. New capital can be added via CapitalReport without rewriting allocator
4. Maintains negative transfer protection under distribution shift

八、死亡条件

D1:
Allocator >= BestSingleCapital regret
=> 二阶智能失败。

D2:
Allocator 只超过 UniformPortfolio，不超过 BestSingleCapital
=> 组合有效，但没有二阶优势。

D3:
Allocator 使用 task_id/env_name/state_dim/utility_type
=> FEATURE_ENGINEERING_REGRESSION。

D4:
HiddenGoalGridWorld 中仍主要选择 PolicyCapital
=> Goal-Inference failure。

D5:
任务切换后持续信任 impaired capital 超过 M 步
=> negative transfer protection failed。

D6:
External benchmark split 上不超过 BestSingleCapital
=> 结果只能标注 SYNTH-ONLY，不能宣称 externally validated。
